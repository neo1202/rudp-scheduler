## Setup

| | |
|---|---|
| Machine | Apple M4 Pro (8 performance + 4 efficiency cores), 12 logical CPUs, darwin/arm64 |
| Go | go1.25.0, GOMAXPROCS 12 |
| Topology | one process: 1 server, N workers, 1 client per job, all on real UDP sockets over loopback |
| Loss model | `internal/lossy` on every socket's send path, so a loss rate of p applies independently to each direction; seeded, no duplication or jitter |
| Transport | epoch 20 ms, window 5, max backoff 8 epochs, epochLimit 10 (default 5, raised so that lost heartbeats cannot end an idle client connection at 20% loss) |
| Scheduler | straggler threshold max(3 x task SRTT, 50 ms), tick 10 ms |
| Workload | hash search, SHA-256; a chunk of 10000 nonces costs about 0.63 ms on one core of this machine, a chunk of 100000 about 4.77 ms |
| Repetitions | every row: 5 fresh clusters (different seeds) x 8 measured jobs = 40 jobs, after one unmeasured warm-up job per cluster; every answer is checked against the sequential result |

Workers and server share one machine, so with 8 workers on 12 cores the workers also compete
with the server and with each other for CPU. Percentiles are nearest-rank over the jobs of a row; with 40 samples p99 is the slowest job.

## 2. Head-of-line blocking

4 workers, 10% loss, chunk = 100000 nonces, 400 chunks per job. The only difference between the rows is
`Params.OrderedDelivery`: the default hands every message up on arrival; the benchmark-only ordered mode
holds a message back until every earlier sequence number has been delivered, like a TCP-style transport.

## 3. Hedging against a straggler

4 workers, no loss, chunk = 100000 nonces, 400 chunks per job. One worker runs at full speed for its first 10
chunks and then takes 50x as long for every chunk (it sleeps after computing), which happens during the
warm-up job; every measured job therefore runs with one degraded worker. Extra work is chunks handed to
workers beyond one per task, as a share of the tasks.

| Speculation | Job time p50 | Job time p99 | Clones issued per job | Extra work | Jobs |
|---|---|---|---|---|---|
| on (default) | 692 ms | 756 ms | 2.7 | 0.7% | 40 |
| off | 3022 ms | 3475 ms | 0.0 | 0.0% | 40 |
